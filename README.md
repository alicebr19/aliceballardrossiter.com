# aliceballardrossiter.com

My name is twenty letters long. This site turns it into three small games.

- **Graph** – every distinct letter is a node and every consecutive pair of letters is a directed edge. Walk the arrows to spell the name. The layout is a small force simulation: nodes repel, edges act as springs, and you can drag anything.
- **Hangman** – guess the letters before the parachute runs out of cords.
- **Boggle** – the name fills a five-by-four board. Trace words of four letters or more, then watch a recursive backtracking search find the ones you missed.

One HTML file, no build step, no dependencies. Open `index.html` in a browser to run it.
